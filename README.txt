# Types of Art and Hobbies

## About the Project

This website introduces different types of art and hobbies. It was created as a practical project to demonstrate basic HTML, CSS, and JavaScript skills.

## Website Sections

- **Home:** Introduction to the topic.
- **Gallery:** Six hobbies, including painting, photography, music, knitting, reading, and sculpture.
- **Benefits:** Information about the benefits of having hobbies.

## Interactive Features

- Navigation links between sections.
- Category filters for the hobby cards.
- Expandable descriptions with additional information.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Files

- `index.html` — the main webpage.
- `design_explanation.docx` — design explanation.
